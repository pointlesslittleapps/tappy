# tappy

one tally mark per tap. that is the entire app.

## what it does

you needed to count something. you don't have enough fingers. your pen is dried up. who uses paper anyway? tap anywhere — mouse or finger — and get a tally mark. it forgets everything when you close the tab, which is either a bug or the point.

## run it locally

just open `tappy.html` in a browser. no build step, no dependencies, no nonsense.

## tech stack

- html
- vanilla javascript (no frameworks, no build tools)
- monospace font (Courier Prime)
